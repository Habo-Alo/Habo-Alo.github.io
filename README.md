## Getting Started

### Prerequisites

- A modern web browser

### Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Habo-Alo/Habo-Alo.github.io.git
   cd Habo-Alo.github.io
   ```


## Usage

Open `index.html` in your web browser to run the application.

```bash
# Or use a local server
npx serve .
```
